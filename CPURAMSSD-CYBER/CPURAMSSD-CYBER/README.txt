CPURAMSSD // DARK CYBER 3D

วิธีใช้งาน
1. นำ cpuramssd.glb ตัวที่ใช้งานได้ มาใส่ในโฟลเดอร์เดียวกับ index.html
2. ดับเบิลคลิก start-server.bat
3. เปิด Chrome แล้วเข้า http://localhost:8000

ฟีเจอร์
- Dark Mystery Cyber UI
- 3D model / OrbitControls
- Auto Rotate / Wireframe / Reset
- CPU / RAM / SSD information modules
- Boot / Glitch / Scanline / HUD effects
- UI sound effects + mute button
- Responsive layout

หมายเหตุ: เว็บโหลดไฟล์ GLB ไม่ใช่ BLEND
